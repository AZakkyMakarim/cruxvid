# FFmpeg dibangun dengan komponen GPL karena app hanya untuk pemakaian pribadi

Cruxvid dipakai sendiri (distribusi manual, bukan store), jadi FFmpeg boleh dibangun dengan encoder GPL seperti x264 di desktop; Android memakai encoder hardware (`h264_mediacodec`). Kalau app dirilis publik, keputusan ini harus dibuka ulang karena mengikat lisensi seluruh paket distribusi.
